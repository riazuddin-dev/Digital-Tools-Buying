# 🛒 Digital Tools Buying Website

##  Description

Digital Tools Buying Website is an online platform where users can browse, select, and purchase various digital tools easily. The website provides a simple and user-friendly interface to manage products and cart functionality.

---

##  Technologies Used

* HTML
* CSS
* JavaScript
* React.js
* Tailwind CSS

---

##  3 Features

* 🔹 Add to Cart functionality
* 🔹 Remove items from cart
* 🔹 Dynamic cart item count display
